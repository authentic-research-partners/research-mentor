# Contributing

Research Mentor is an opinionated project with a specific pedagogical philosophy. We welcome interest in collaboration, but we don't accept unsolicited pull requests.

## How to get involved

1. **Open an issue** describing what you'd like to work on or improve.
2. **Wait for a conversation** - we'll discuss whether the change fits the project's direction.
3. **Only then** fork and submit a pull request.

Pull requests submitted without prior discussion will be closed.

## Bug reports

Bug reports are always welcome. Please open an issue with:
- Steps to reproduce
- Expected vs. actual behavior
- Your OS and Python version

## Security vulnerabilities

If you find a security vulnerability, please report it privately - do **not** open a public issue. Email hello@arpconnect.com with details.

## Questions and ideas

For general questions, feature ideas, or collaboration proposals, open an issue or reach out at https://arpconnect.com.
